# 🚲 Bike Shop Website (Website Bán Xe Đạp Cao Cấp)

Dự án website thương mại điện tử chuyên cung cấp các dòng xe đạp cao cấp, được xây dựng tập trung vào trải nghiệm người dùng (UX/UI) và tính năng tương tác mượt mà trên giao diện Web Frontend.

## 🛠 Công nghệ sử dụng (Tech Stack)
* **HTML5**: Xây dựng cấu trúc trang web chuẩn SEO và tối ưu semantic.
* **CSS3**: Thiết kế giao diện hiện đại với CSS Grid & Flexbox, hỗ trợ Responsive trên mọi thiết bị.
* **JavaScript (ES6+)**: Xử lý logic tương tác động, quản lý dữ liệu sản phẩm và giỏ hàng.

## ✨ Tính năng nổi bật (Key Features)
* **Trang chủ trực quan**: Bố cục banner bắt mắt, giới thiệu các dòng sản phẩm nổi bật.
* **Quản lý sản phẩm**: Hiển thị danh sách sản phẩm chi tiết, hình ảnh sắc nét.
* **Giỏ hàng tương tác**: Thêm, xóa sản phẩm và cập nhật tổng tiền nhanh chóng.
* **Responsive Design**: Tối ưu hiển thị mượt mà trên cả máy tính, máy tính bảng và điện thoại di động.
